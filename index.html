How to use

사진 넣기 · 백업 · 보관

처음 상태의 모든 사진 자리는 검은색 (사진) 빈칸입니다. 세 가지 방법으로 채웁니다.

1

카드에서 바로 사진 넣기

카드를 눌러 상세를 열고 (사진) 칸을 클릭하면 파일 선택창이 뜹니다. 넣은 사진은 이 브라우저에 저장되어 새로고침해도 유지됩니다. × 를 누르면 빈칸으로 되돌아갑니다.

2

저장소에 사진 올려 연결하기

사진을 assets/photos/ 에 올리고 assets/js/data.js 의 src: null 을 경로로 바꿉니다. 이 방법은 어느 기기에서나 똑같이 보이고, 기록이 저장소에 남습니다.

3

JSON 백업 · 복원

상단 JSON 내보내기 로 지금까지의 케이스와 사진을 파일 하나로 내려받습니다. 다른 기기에서 가져오기 로 불러오면 이어서 작업할 수 있습니다.

기본 8개 케이스는 구조 예시입니다. 실제 실습 기록으로 제목·수치·피드백을 바꿔 쓰세요. 원내생진료 슬롯 2개는 본3 진료가 시작될 때 그대로 복제해 쓰도록 만들어 두었습니다. 사진에는 환자 식별 정보(얼굴, 이름, 차트 번호)가 찍히지 않게 해 주세요.

전임상 실습과 원내생진료 프렙 기록을 위한 개인 포트폴리오입니다. 학습 목적의 기록이며, 실제 진료에 사용하는 자료가 아닙니다.
